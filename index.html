2 Enter DFU Mode

Put your device into DFU bootloader mode:

  1. Set the BOOT0 jumper (or hold the BOOT button)
  2. Press RESET (or reconnect the USB cable)
  3. Release BOOT0 / button
Running Candlelight firmware?

Candlelight firmware supports entering DFU over USB without the BOOT0 jumper:

Windows: "Access denied" when connecting?

The STM32 DFU bootloader needs the WinUSB driver. Install it with Zadig:

  1. Put the device in DFU mode (BOOT0 + reset)
  2. Open Zadig → Options → List All Devices
  3. Select STM32 BOOTLOADER from the dropdown
  4. Set the driver to WinUSB and click Replace Driver

This only needs to be done once per device type.
